# Trabalho_Final_Lab._de_Programacao
Sistema integrado de agendamento de reuniões implementado em três paradigmas de programação: orquestrador orientado a objetos em Python, módulo lógico em SWI-Prolog (CSP) e módulo funcional em Common Lisp, comunicando-se por contrato JSON via stdin/stdout. Trabalho final de Laboratório de Programaçã
